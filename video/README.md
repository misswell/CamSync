# CamSync 宣传动画

`camsync-promo-9x16.mp4` — 1080×1920(9:16 竖版)、30fps、约 37 秒、无音频(建议发布时在抖音/视频号/小红书编辑器内配平台热门音乐,利于推荐)。

结尾引导为「App Store 搜索 CamSync」文字按钮,**没有二维码**(避免平台限流)。

## 分镜

| 时间 | 场景 |
| --- | --- |
| 0.0–4.3s | 痛点开场(深色):SD 卡弹出照片,"拍了很多好照片,然后呢?" |
| 4.3–8.1s | 品牌亮相:App 图标 + CamSync + "让照片,继续出发" |
| 8.1–14.6s | 01 连接你的灵感:相机/SD/USB → iPhone(系统文件选择器授权) |
| 14.6–21.1s | 02 挑选值得留下的:九宫格勾选 + 已选/新增/全部/时间段 |
| 21.1–27.6s | 03 去你想去的地方:相册/文件夹/iCloud Drive,1 分钟 100 张 |
| 27.6–31.9s | 深色安心页:确实存好才算完成 + 隐私三承诺 |
| 31.9–37.0s | 结尾:图标 + App Store 搜索引导 |

视觉沿用官网风格:纸白 #F4F3EF / 墨黑 #20231F / 橙 #FA5728,真实 App 图标取自 `website/public/assets/app-icon.png`。

## 重新渲染 / 修改

```bash
cd video
python3 render_promo.py                 # 全片 → camsync-promo-9x16.mp4(约 3 分钟)
python3 render_promo.py --stills 2.6,29.5   # 只渲染指定秒数的静帧用于预览
```

所有文案、时间轴(分镜表 `scene(...)` 与 `SCENES`)、配色都在 `render_promo.py` 顶部/各 `s0–s6` 场景函数里,改完重跑即可。
