# CamSync

CamSync 是一个原生 SwiftUI iOS 应用，用系统文件选择器读取已挂载到“文件”App 的相机、读卡器、USB 存储或文件夹，并将照片可靠地同步到系统照片图库、本机文件夹或 iCloud Drive。

## 已实现

- 手动选择外部设备/源文件夹，首页按目录层级浏览，不加载缩略图
- 进入某个照片详情弹窗后才懒加载可见缩略图，保持照片原始横竖比例，并限制缓存大小
- 先选择照片或下载范围，最后才选择保存位置；支持已选、新增、全部和时间段四种方式
- “今天”严格从当天 00:00 开始，不会混入昨天同一时刻之后的照片
- 系统照片目标按 PhotoKit 文件夹/相册层级浏览，每层均可新建相册或子文件夹
- 文件目标：选择本机或 iCloud Drive 文件夹并保留源目录结构
- 最多 3 路并发传输，大文件采用 1 MB 流式读写与 SHA-256
- SQLite WAL 同步账本，按设备保存设置、成功项及每次失败/中断尝试
- 目标写入成功后才用数据库事务提交成功状态
- 文件写入使用 `.partial` 临时文件，完成后原子移动
- 若文件已完成移动但应用恰好在数据库提交前退出，重试会校验源/目标 SHA-256 并补记成功，不会再复制一份
- 设备重连后恢复设置、统计并提示新增照片，但不会自动开始同步
- 清除当前设备历史（不删除目标中的照片）

## 运行

用 Xcode 26 或更新版本打开 `CamSync.xcodeproj`，选择开发团队和真机后运行。系统照片写入及外部设备访问建议使用真机验证。

## iOS 平台限制

iOS 没有向第三方应用开放通用的 PTP/MTP 相机枚举 API。相机或读卡器需要先能在系统“文件”App 中显示，用户再通过 CamSync 的系统文件选择器授权目录。应用无法在未启动、未获目录授权时静默监控 USB 插拔；重新连接后 CamSync 会统计新增照片，并等待用户选择下载方式。
